## Locked In Toolbox (LIT)
Locked In Toolbox is a web based study app designed to help students track and improve their study habits. It combines a study timer with tasks, flashcards, and a dashboard that shows past study sessions.

## Features
- Study timer with various modes and session summaries
- Task checklist and flashcards for an active study
- Dashboard with study statistics and a calendar view of past sessions
- AI feedback after completing a study session

## How to Run
cd LIT-FrontEnd
npm install
npm run dev
